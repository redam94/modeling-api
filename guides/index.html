    These guides are for persons who use the platform: analysts, data scientists and clients. Each guide does one task from start to end.

    • Build a dashboard¶

      Publish the results of a model to a client.

      Build a client dashboard

    • Choose a model¶

      Answer some questions and get a ranked shortlist.

      Choose a model

    • Check a model¶

      Prove that a model is better than noise.

      Read about null tests

    Data¶

    • From a spreadsheet to a Guided draft Upload a spreadsheet and make a Guided draft with the HTTP API.
    • Tree datasets, HDF5 and multi-file versions Use NetCDF and HDF5 groups, and make one version from many files.
    • Image data Upload a folder of images, look at them and classify them.
    • Explore a dataset Find gaps, outliers, trends and seasons before you fit a model.

    Models¶

    • Choose a model Use the About cards and Help me choose to find the correct model.
    • Guided modelling Set priors in business terms, add lift tests and read the scorecard.
    • Marketing-mix models (MMM) Fit an MMM and get the return of each channel.
    • Forecasting and sequential models Make forecasts that start from the correct history.
    • statsmodels time-series models Use twelve classical models, from SARIMAX to VECM.
    • Measure the effect of a change Measure the effect of a campaign, a launch or a price change.
    • Deep learning Train neural networks on tables and images.
    • Bring a PyMC model Write one build() method and run your PyMC model on the platform.
    • Tabular models Use scikit-learn, xgboost, LightGBM and CatBoost estimators.

    Trust and compare¶

    • Can you trust this model? Learn why a model must be better than noise, in plain words.
    • Validate models with governance policies Apply a policy, get the approval of a second person and keep the evidence.
    • Track metrics, params and tags Log metrics, params, tags and images in each run.
    • Compare runs and use experiments Find runs, compare them side by side and group them.
    • Explore a model See what a fitted model learned and how well it works.

    Workflows¶

    • Workflows Build, run and schedule a full analysis as one graph.
    • Workflow cookbook Copy one of ten complete, tested analyses.

    Plots¶

    • Plots, recipes and templates Use the standard plots of a model and add your own.
    • Share plots Save a plot, export an image or make an embed link.

    Dashboards and clients¶

    • Build a client dashboard Make a dashboard from a model or an endpoint and publish it. Analyst
    • Share a dashboard with a link Make, send and revoke a share link with a passcode. Analyst
    • Read your dashboard Open your dashboard and read the numbers. You do not need statistics. Client
    • Ask about your dashboard Ask an AI assistant about the numbers on a dashboard. Client
    • Connect a chat tool with MCP Let a desktop assistant or an agent read one dashboard. Developer

    Automate¶

    • Endpoints and webhooks Serve a model under a stable name and get signed events.
    • The Integrations hub Connect a model to Google Sheets, a BI tool or a webhook.
    • The command line Use the mapi command on your computer or on a platform.
    • The Python client Control the platform from Python with mapi_client.
    • The HTTP API Do the main flow with curl, one request at a time.
