    Write a step or a model plugin¶

    A plugin author writes very little: a step implements fit/transform (and inverse when it can); a model implements fit/score. The platform owns everything around them — binding, splits, context tails, coordinates, inverse transforms, summaries and bundles. The contract kit tells you, before anyone else runs your code, whether you followed the rules.

    A preprocessing step¶

    from typing import ClassVar

from mapi_sdk import Step, StepContext, StepSettings, StepState
from mapi_spec import StepKind
from pydantic import Field, JsonValue


class ScaleSettings(StepSettings):
    vars: list[str]
    over: list[str] = Field(default=[])  # plain defaults: the exported JSON Schema keeps them
    unseen_levels: str = "error"  # error | pooled | fill: what a new level's scale becomes
    fill_value: float = 1.0  # the scale used by 'fill'


class ScaleStep(Step[ScaleSettings, StepState]):
    """Divide each variable by its mean absolute value over `over` (learned on train)."""

    id = "acme.scale"
    version = "1.0.0"
    kind = StepKind.VALUE
    Settings = ScaleSettings
    State = StepState  # stateful: fitted on the training data only
    invertible = True
    var_params = ("vars",)  # settings that name variables ...
    dim_params = ("over",)  # ... and dims, so the control plane can check them
    unseen_levels_param = "unseen_levels"
    effect_template: ClassVar[dict[str, JsonValue]] = {  # static: how the schema changes
        "template_params": ["vars"],
        "updates": {"{*vars as v}": {"units": "1"}},
    }
    summary = "Divide by the mean absolute value over the named dims"  # catalog and UI text
    summary_plain = "Puts each series on a comparable scale"

    def fit(self, ds: xr.Dataset, s: ScaleSettings, ctx: StepContext) -> StepState:
        return StepState(arrays=xr.Dataset({f"scale__{v}": abs(ds[v]).mean(s.over) for v in s.vars}))

    def _scale(self, v: str, ds: xr.Dataset, s: ScaleSettings, st: StepState, ctx: StepContext):
        state = st.array(f"scale__{v}")
        return ctx.align_state(state, ds, s.unseen_levels, fill_value=s.fill_value)

    def transform(self, ds, s, st, ctx):  # never learns; skips absent vars (the target at score)
        return ds.assign({v: ds[v] / self._scale(v, ds, s, st, ctx) for v in s.vars if v in ds})

    def inverse(self, ds, s, st, ctx):
        return ds.assign({v: ds[v] * self._scale(v, ds, s, st, ctx) for v in s.vars if v in ds})

    The rules:

    • transform never learns. transform(train, fit(train)) must equal the fit-time output, and a subset of the data must transform to the same subset of the output.
    • Reductions name the dims they reduce over; state stays labelled by the rest.
    • Steps that look back (lags, rolling windows) declare context_template ({"along": "{along}", "n": "{max:lags}", "within": "{within}"}). The platform stores the last n rows per group at the step's input and prepends them at score time.
    • Unseen levels go through ctx.align_state(state, ds, policy).
    • effect_template must describe the real output schema — the control plane validates specs with it and never imports your code.

    A model¶

    from mapi_sdk import PREDICTIONS, CustomModel, FitOutput, ModelSettings, new_level_mask
from mapi_spec import Capabilities, DataSchema, Representation


class BaselineSettings(ModelSettings):
    ridge: float = 1e-6


class GeoBaseline(CustomModel[BaselineSettings]):
    """y = intercept[geo] + beta * spend, by least squares (point predictions)."""

    id = "acme.geo_baseline"
    version = "1.0.0"
    Settings = BaselineSettings
    capabilities = Capabilities(
        inference="point",
        representation=Representation.POINT,
        score_modes=frozenset({"predict", "forecast", "evaluate"}),
    )
    # the data contract the model needs, in canonical names (a DataSchema, or a
    # DataSchemaTemplate whose names come from settings)
    schema_template = DataSchema.model_validate(
        {
            "dims": {
                "geo": {"kind": "categorical", "policy": "new_levels", "new_level_strategy": "pooled"},
                "time": {"kind": "time", "policy": "extend"},
            },
            "vars": {
                "y": {"dims": ["geo", "time"], "dtype": "float64", "role": "target"},
                "spend": {"dims": ["geo", "time"], "dtype": "float64", "role": "covariate"},
            },
        }
    )
    outputs: ClassVar[dict] = {"y_hat": {"dims": ["geo", "time"], "units_of": "y"}}
    pad_extend = False  # time is not indexed by position

    def fit(self, ds, s, cfg, ctx):
        g, t = ds.sizes["geo"], ds.sizes["time"]
        x = np.concatenate(
            [np.repeat(np.eye(g), t, axis=0), ds["spend"].values.reshape(-1, 1)], axis=1
        )
        coef = np.linalg.solve(x.T @ x + s.ridge * np.eye(g + 1), x.T @ ds["y"].values.ravel())
        params = xr.Dataset(
            {"intercept": ("geo", coef[:g]), "beta": coef[g]}, coords={"geo": ds["geo"].values}
        )
        return FitOutput(groups={"params": params})

    def score(self, fitted, ds, req, ctx):
        # `ds` arrives canonicalised: fit order, unseen geos appended and flagged
        p = fitted.group("params")
        new = new_level_mask(ds, "geo")
        known = p["intercept"].reindex(geo=ds["geo"].values)
        pooled = 0.0 if ctx.strategy("geo") == "zero" else float(p["intercept"].mean())
        intercept = xr.where(new, pooled, known.fillna(pooled))
        y_hat = (intercept + p["beta"] * ds["spend"]).transpose("geo", "time")
        return xr.DataTree.from_dict({PREDICTIONS: xr.Dataset({"y_hat": y_hat})})

    outputs lists every variable score returns with its dims (representation dims such as chain/draw or quantile may be left out). When the data dims depend on settings, add "dims_of": "y": the output then also carries every dim of that input variable in the resolved schema (for example the sklearn models' settings.rows).

    FitOutput.native is for safe native formats only (skops, xgboost JSON, safetensors). Pickle is rejected when a bundle is written and when it is read.

    Run the contract kit¶

    mapi-sdk installs a pytest plugin, so the fixtures are available in any test suite:

    import pytest
from mapi_sdk.testing import ModelFixture, toy  # toy: small reference steps and models


@pytest.mark.mapi_contract
def test_step_follows_the_contract(mapi_check_step, mapi_panel):
    data, _fx = mapi_panel  # a daily market x channel panel and its FX side table
    report = mapi_check_step(
        toy.ScaleStep, data, {"vars": ["spend_local"], "over": ["date"], "unseen_levels": "pooled"}
    )
    assert report.ok, report.summary()


SPEC = """
apiVersion: mapi/v1
kind: ModelSpec
metadata: {name: toy, project: demo}
data:
  dataset: dataset://demo/panel@latest
  bind: {dims: {geo: market, time: date}, vars: {y: revenue_local, spend: spend_local}}
  split: {kind: time_holdout, dim: time, last: 14}
model: {use: toy.linear@^1, fit: {seed: 1}}
evaluate: {metrics: [rmse]}
"""


@pytest.mark.mapi_contract
def test_model_follows_the_contract(mapi_check_model, mapi_panel, mapi_toy_registry):
    data, _fx = mapi_panel
    fixture = ModelFixture(spec=SPEC, data=data, registry=mapi_toy_registry)
    report = mapi_check_model(toy.LinearModel, fixture)  # raises ContractViolation on failure
    assert report.ok

    check_step checks the exported catalog entry, deterministic fitting, a pure and deterministic transform, that transform never learns, the state's bundle round trip, that the declared schema effect matches the real output, that a missing target is tolerated, the inverse round trip, context-window equivalence and every unseen-level policy.

    check_model fits the fixture and checks the bundle round trip (and that it has no pickle), shuffled and subset scoring, new-level policies, the typed errors of every dim policy (gaps and out-of-range coordinates on datetime and integer extend dims, HORIZON_EXCEEDS_FIT past max_extension, MISSING_FUTURE_COVARIATE for a forecast without a future-required variable, RECURSIVE_UNSUPPORTED for a horizon longer than a target lag), unsupported modes, context-window equivalence, that the evaluation metrics are reproduced by the score path, output units (including outputs that inherit the target's units), that every returned prediction is declared in outputs with matching dims, legal aggregation, additive contributions, seed determinism, that the manifest's plots render and pass the sanitizer, and — when the manifest declares fast_score — that fast scoring matches exact scoring within MCSE. That last check calls the plugin's check_fast_score(fitted, ds, *, seed) hook; PyMCModel provides it.

    A failed check raises ContractViolation with a readable report:

    contract kit: step acme.scale@1.0.0
  [PASS] catalog_entry: exported acme.scale@1.0.0
  [FAIL] transform_never_learns: AssertionError: ...

    mapi_sdk.testing.toy holds small, real reference implementations (scale, log1p, lag, resample, Fourier, FX steps; point, draws and quantile models) to copy from.
