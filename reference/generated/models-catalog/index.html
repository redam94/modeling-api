    choice.multinomial_logit¶

    Which product customers choose on each shopping trip: a conditional (multinomial) logit over alternative-specific covariates such as price and promotion, with household-specific product preferences. Uncertainty comes from the Bayesian bootstrap over households; new households draw their preferences from the fitted spread.
    Version 1.0.0
    Inference bootstrap
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict
    Contributions none
    Decision objective –
    Fast scoring –
    Owns –
    LOO invalid: bootstrap draws have no pointwise log-likelihood
    Default plots core.data_overview, core.posterior_forest
    Resources class S (min S)

    Outputs

    Output Dims Units Description
    y_hat (hh, trip, product) probability Choice probability of each product per household and trip (predictive: one sampled choice, one-hot)

    Settings (model.settings)

    Field Type Default Level Description
    covariates list of string (optional) null advanced Alternative-specific variables along product (default: every numeric variable with the product dim)
    random_effects list of hh ["hh"] advanced Household-specific product intercepts ([hh]) or none ([]) (max items 1)
    effect_sd number 1.0 advanced Prior sd of the household effects (smaller pools households more) (> 0, ≤ 10)
    coef_sd number 10.0 advanced Prior sd of the product intercepts and coefficients (weak) (> 0, ≤ 1000)
    reference string (optional) null advanced Product whose intercept is fixed at 0 (default: the first label)
    max_iter integer 500 advanced ≥ 10, ≤ 10000
    Input data contract (schema template)

  "params": {
    "covariates": {
      "type": "string_list",
      "path": "covariates",
      "default": []
    }
  },
  "template": {
    "dims": {
      "hh": {
        "kind": "categorical",
        "policy": "new_levels",
        "new_level_strategy": "hyperprior"
      },
      "trip": {
        "kind": "index",
        "policy": "extend"
      },
      "product": {
        "kind": "categorical",
        "policy": "fixed"
      }
    },
    "vars": {
      "y": {
        "dims": [
          "hh",
          "trip"
        ],
        "dtype": "str",
        "role": "target",
        "missing": "allow"
      },
      "{*covariates as v}": {
        "dims": [
          "hh",
          "trip",
          "product"
        ],
        "dtype": "float64",
        "role": "covariate",
        "missing": "allow"
      }
    }
  }

    mmm.bayesinsight¶

    A BayesInsight model_def.json as a built-in model: Normal, log-normal, Poisson, negative binomial and zero-inflated likelihoods, coefficient priors in KPI units, Hill, linear and S-shaped curves with delayed, geometric or Weibull carry-over, sign constraints, fixed and partially pooled effects per row id, Fourier seasons and local spline trends.
    Version 1.0.0
    Inference mcmc
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict, simulate
    Contributions additive
    Decision objective –
    Fast scoring –
    Owns –
    LOO valid
    Default plots core.ppc_fan, core.convergence, core.posterior_forest
    Resources class M (min S)

    Outputs

    Output Dims Units Description
    y_hat (time) of y Expected (or predictive) KPI over the panel dims and time
    contributions (component, time) of y Media, baseline (intercepts), controls, seasons and trends in KPI units; they sum to the expected KPI (log-mean Divisia split for log links)

    Settings (model.settings)

    Field Type Default Level Description
    model_def BayesInsightModel required advanced BayesInsight's model_def.json (variable_details); priors in KPI units
    variables map of string required advanced Analytic variable name -> model-stage variable (the KPI is 'y')
    media list of string – advanced Model-stage media variables (lag tensors), in model_def order (max items 128)
    controls list of string – advanced Model-stage control variables, in model_def order (max items 256)
    row_dims map of string – advanced BayesInsight row id -> panel dim of the model-stage data
    panel list of string – advanced The panel dims (row_dims in BayesInsight's row order) (max items 5)
    l_max integer 12 advanced Carry-over lags (the lag tensor's l_max) (≥ 1, ≤ 104)
    lag_dim string lag advanced Lag dim of the media tensors

    DelayedAdstockPrior¶

    alpha ~ Beta(mu=retention_rate_mean, nu=retention_rate_std) and theta ~ Exponential(lam=lag_max) (BayesInsight's DelayedAdStockPrior; lag_min is kept but unused, as in BayesInsight). Geometric adstock uses the retention prior alone.

    Field Type Default Description
    type Delayed Delayed
    retention_rate_mean number 0.2 > 0, < 1
    retention_rate_std number 10.0 > 0
    lag_min number 0.0001 > 0
    lag_max number 3.0 > 0

    DeterministicTransform¶

    A transform with known parameters: linear x, log log(x), exp 1 - exp(-x / alpha), indexp 1 - exp(-x / mean * alpha), power x^alpha (BayesInsight's DeterministicTransform).

    Field Type Default Description
    functional_form linear or log or exp or indexp or power linear
    params map of number (optional) null

    HillPrior¶

    K ~ LogNormal(log K_ave, log(K_std / K_ave + 1)) and n = 1 + Exponential(1 / (n_ave - 1)) (BayesInsight's HillPrior; n_std is kept but unused, as in BayesInsight, and n_ave must exceed 1).

    Field Type Default Description
    type Hill Hill
    K_ave number 0.85 > 0
    K_std number 0.6 > 0
    n_ave number 1.5 > 1
    n_std number 1.2 > 0

    Likelihood¶

    The KPI's likelihood. likelihood_params parametrise the dispersion prior: sigma ~ HalfNormal(**params) (Normal, LogNormal; default sigma=1), alpha ~ Gamma(**params) (negative binomials; default alpha=2, beta=0.001) or psi ~ Beta(**params) (zero-inflated Poisson; default alpha=1, beta=1). The zero-inflated negative binomial takes alpha from the params and psi ~ Beta(1, 1). dispersion_dims give sigma/alpha one value per level of those row ids.

    Field Type Default Description
    type Normal or LogNormal or Poisson or NegativeBinomial or ZeroInflatedPoisson or ZeroInflatedNegativeBinomial required
    likelihood_params map of number (optional) null
    dispersion_dims list of Geography or Product or Outlet or Campaign or Creative (optional) null

    LocalTrendPrior¶

    BayesInsight's LocalTrendPrior (variability: the random walk's step scale, group_variablility - spelled as in BayesInsight - the spread of levels around the shared walk, partial_pooling the spread within a group, initial_dist_var the sd of the walk's first value).

    Field Type Default Description
    type LocalTrend LocalTrend
    variability number 0.2 > 0
    group_variablility number 0.01 > 0
    partial_pooling number 0.01 > 0
