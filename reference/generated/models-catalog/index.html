    choice.multinomial_logit¶

    Which product customers choose on each shopping trip: a conditional (multinomial) logit over alternative-specific covariates such as price and promotion, with household-specific product preferences. Uncertainty comes from the Bayesian bootstrap over households; new households draw their preferences from the fitted spread.
    Version 1.0.0
    Inference bootstrap
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict
    Contributions none
    Decision objective –
    Fast scoring –
    Owns –
    LOO invalid: bootstrap draws have no pointwise log-likelihood
    Default plots core.data_overview, core.posterior_forest
    Resources class S (min S)

    Outputs

    Output Dims Units Description
    y_hat (hh, trip, product) probability Choice probability of each product per household and trip (predictive: one sampled choice, one-hot)

    Settings (model.settings)

    Field Type Default Level Description
    covariates list of string (optional) null advanced Alternative-specific variables along product (default: every numeric variable with the product dim)
    random_effects list of hh ["hh"] advanced Household-specific product intercepts ([hh]) or none ([]) (max items 1)
    effect_sd number 1.0 advanced Prior sd of the household effects (smaller pools households more) (> 0, ≤ 10)
    coef_sd number 10.0 advanced Prior sd of the product intercepts and coefficients (weak) (> 0, ≤ 1000)
    reference string (optional) null advanced Product whose intercept is fixed at 0 (default: the first label)
    max_iter integer 500 advanced ≥ 10, ≤ 10000
    Input data contract (schema template) 
    {
  "params": {
    "covariates": {
      "type": "string_list",
      "path": "covariates",
      "default": []
    }
  },
  "template": {
    "dims": {
      "hh": {
        "kind": "categorical",
        "policy": "new_levels",
        "new_level_strategy": "hyperprior"
      },
      "trip": {
        "kind": "index",
        "policy": "extend"
      },
      "product": {
        "kind": "categorical",
        "policy": "fixed"
      }
    },
    "vars": {
      "y": {
        "dims": [
          "hh",
          "trip"
        ],
        "dtype": "str",
        "role": "target",
        "missing": "allow"
      },
      "{*covariates as v}": {
        "dims": [
          "hh",
          "trip",
          "product"
        ],
        "dtype": "float64",
        "role": "covariate",
        "missing": "allow"
      }
    }
  }

    mmm.bayesian¶

    mmm-framework's Bayesian marketing-mix model: adstock and saturation per channel, trend and seasonality, national or hierarchical over geos and products, channel effects stated as returns on spend, business priors and lift tests as calibration, budget optimisation with mmm-framework planning.
    Version 1.0.0
    Inference mcmc
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict
    Contributions additive
    Decision objective yes
    Fast scoring –
    Owns carryover, inverse_units, scaling
    LOO valid
    Default plots core.ppc_fan, core.convergence, core.posterior_forest, mmm.decomposition, mmm.response_curves, mmm.marginal_cost
    Resources class M (min S)

    Outputs

    Output Dims Units Description
    y_hat (time) of y Expected (or predictive) KPI over the panel dims and time
    contributions (component, time) of y Every channel, the baseline, trend, seasonality and each control; they sum to y_hat

    Derived quantities (outputs.derived)

    Name Dims Units Cached Description
    contributions (sample, channel, time) target fit Channel, baseline, trend, seasonality and control contributions over the fit window per thinned draw (panel dims included)
    response_curves (sample, channel, multiplier) target fit Total contribution per spend multiplier and channel (and geo) per thinned draw (Guided-mode slider grids, budget optimisation)
    marginal_cost (sample, channel) spend per target fit Extra spend per extra unit of the KPI at current spend

    Settings (model.settings)

    Field Type Default Level Description
    adstock AdstockSettings {"kind": "geometric", "l_max": 8, "normalize": true} basic
    saturation SaturationSettings {"kind": "logistic"} basic
    channels map of ChannelSettings – advanced Per-channel adstock/saturation overrides (channel label -> settings)
    trend TrendSettings {"kind": "linear", "n_changepoints": 10, "changepoint_range… basic
    seasonality SeasonalitySettings {"yearly_order": 2, "monthly_order": null, "weekly_order": … basic
    hierarchy HierarchySettings {"pool_over": [], "media_by_geo": false, "media_geo_sigma":… basic
    controls list of string (optional) null advanced Control variables (default: every other numeric variable over time)
    frequency W or D or M (optional) null advanced Data frequency: W (weekly), D (daily) or M (monthly); default: read from the time labels
    new_levels pooled or hyperprior or zero or error pooled advanced How a geo or product unseen at fit is scored: pooled (the overall level and average channel effects), hyperprior (a level drawn from the fitted spread, so its range is wider), zero (no channel effects) or error (refuse)
    grid GridSettings {"max_multiplier": 2.5, "points": 26, "marginal_step": 0.01} advanced
    media_prior roi or coefficient roi advanced Parameterise channel effects by their return on spend (priors are stated in ROI, comparable across channels) or by a standardised coefficient
    priors PriorSettings {"roi": {}, "roi_default": null, "intercept": null} advanced Prior overrides (written by business-prior translation)
    likelihood normal or student_t normal advanced Observation noise: normal, or student_t for heavy-tailed outliers
    Nested settings types

    AdstockSettings¶

    Carry-over of spend into later periods (mmm-framework AdstockConfig).

    Field Type Default Description
    kind geometric or delayed or weibull or none geometric geometric: decays from the spend period; delayed: peaks a few periods later; weibull: a flexible shape; none: no carry-over
    l_max integer 8 How many periods an effect can last (the kernel length) (≥ 1, ≤ 52)
    normalize boolean true Normalise the lag weights to sum to one (the effect size stays in the channel coefficient)

    ChannelSettings¶

    Per-channel overrides of the shared adstock and saturation settings.

    Field Type Default Description
    adstock AdstockSettings (optional) null
    saturation SaturationSettings (optional) null

    GridSettings¶

    Response-curve grids cached per thinned draw (Guided-mode sliders, optimisation).

    Field Type Default Description
    max_multiplier number 2.5 Largest spend multiplier on the grid (1 = spend over the fit window, which the grid always holds) (≥ 1, ≤ 20)
    points integer 26 Grid points from 0 to max_multiplier (plus 1, today's spend, when the spacing skips it) (≥ 3, ≤ 201)
    marginal_step number 0.01 Relative spend change used for marginal cost (central difference) (> 0, ≤ 0.25)

    HierarchySettings¶

    Panel structure: the dims the KPI varies over besides time. pool_over lists the panel dims of the data (geo and/or product). Every level gets its own baseline, partially pooled towards the overall level (HierarchicalConfig.pool_across_geo/product); with media_by_geo each geo also gets its own channel effects, partially pooled across geos.

    Field Type Default Description
    pool_over list of geo or product – Panel dims of the data (geo, product); empty for one national series (max items 2)
    media_by_geo boolean false Let channel effects differ by geo (partially pooled)
    media_geo_sigma number 0.3 Prior sd of the geo deviations of log channel effects (> 0, ≤ 5)

    NormalPrior¶

    Normal(mu, sigma) on the standardised KPI scale (KPI standard deviations).

    Field Type Default Description
    mu number required ≥ -50, ≤ 50
    sigma number required > 0, ≤ 50

    PriorSettings¶

    Prior overrides; business-prior translation (translate_priors) writes them. * roi - per channel, a log-normal prior on the return on spend (mmm-framework's ROI-parameterised channel effect, roi_prior_mu/roi_prior_sigma); * roi_default - the log-normal ROI prior of channels not listed (default LogNormal(0, 1): median break-even); * intercept - the baseline level in KPI standard deviations from the mean.

    Field Type Default Description
    roi map of RoiPrior – Per-channel log-normal ROI priors (channel label -> {mu, sigma})
    roi_default RoiPrior (optional) null
    intercept NormalPrior (optional) null

    RoiPrior¶

    A log-normal prior on a channel's return on spend (KPI per unit of spend over the fit window): roi ~ LogNormal(mu, sigma), so exp(mu) is the median ROI.

    Field Type Default Description
    mu number required Log of the median ROI (≥ -20, ≤ 20)
    sigma number required Spread on the log scale (> 0, ≤ 10)

    SaturationSettings¶

    Diminishing returns of (carried-over) spend (mmm-framework SaturationConfig).

    Field Type Default Description
    kind logistic or hill or michaelis_menten or tanh or root or none logistic logistic (default, most stable), hill (S-shaped), michaelis_menten, tanh, root (power curve) or none (a straight line)

    SeasonalitySettings¶

    Fourier seasonality (mmm-framework SeasonalityConfig).

    Field Type Default Description
    yearly_order integer (optional) 2 Fourier pairs of the yearly cycle (0 or null: none)
    monthly_order integer (optional) null
    weekly_order integer (optional) null Daily data only
    prior_sigma number 0.3 Prior sd of each Fourier coefficient, in KPI standard deviations (raise it for strongly seasonal categories) (> 0, ≤ 5)

    TrendSettings¶

    The slow-moving baseline (mmm-framework TrendConfig).

    Field Type Default Description
    kind none or linear or piecewise or spline or gp linear none, linear (default), piecewise (Prophet-style changepoints), spline or gp (a smooth Gaussian-process curve). Forecasts hold flexible trends at their last fitted level; a linear trend is extrapolated.
    n_changepoints integer 10 ≥ 1, ≤ 50
    changepoint_range number 0.8 > 0, ≤ 1
    n_knots integer 10 ≥ 3, ≤ 50
    growth_prior_sigma number 0.5 Prior sd of the linear slope, in KPI standard deviations over the whole history (> 0, ≤ 10)
    Input data contract (schema template) 
    {
  "params": {
    "panel": {
      "type": "string_list",
      "path": "hierarchy.pool_over",
      "default": []
    },
    "strategy": {
      "type": "string",
      "path": "new_levels",
      "enum": [
        "pooled",
        "hyperprior",
        "zero",
        "error"
      ],
      "default": "pooled"
    }
  },
  "template": {
