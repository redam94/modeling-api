    mmm.hierarchical_geo¶

    Hierarchical geo marketing-mix model: geometric/delayed adstock over a lag tensor, logistic or Hill saturation, channel effects partially pooled across geos, new geos drawn from the hyperprior, additive contributions, response curves and marginal costs in original units, and a budget objective for optimisation.
    Version 1.3.0
    Inference mcmc
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict, simulate
    Contributions additive
    Decision objective yes
    Fast scoring yes
    Owns –
    LOO valid
    Default plots core.ppc_fan, core.convergence, core.posterior_forest, mmm.decomposition, mmm.response_curves, mmm.marginal_cost
    Resources class M (min S)

    Outputs

    Output Dims Units Description
    y_hat (geo, time) of y Expected (or predictive) target
    contributions (component, geo, time) of y Additive contribution of each channel, the baseline and each control; sums to y_hat

    Derived quantities (outputs.derived)

    Name Dims Units Cached Description
    contributions (sample, channel, geo, time) target fit Channel, baseline and control contributions over the fit window per thinned draw, in original units
    response_curves (sample, channel, multiplier, geo) target fit Total contribution per spend multiplier, channel and geo per thinned draw (Guided-mode slider grids)
    marginal_cost (sample, channel, geo) spend per target fit Extra spend per extra unit of the target at current spend

    Settings (model.settings)

    Field Type Default Level Description
    pooling partial or complete or none partial basic How channel effects are shared across geos: partial pooling (default), one effect for all geos, or independent geos (no new geos at score time)
    centred boolean false advanced Centred parameterisation of the geo-level effects (non-centred samples better with few geos or little data per geo)
    adstock AdstockSettings {"kind": "geometric", "l_max": null, "normalize": true} basic
    saturation SaturationSettings {"kind": "logistic"} basic
    priors Priors {"intercept": null, "intercept_sigma": null, "beta_channel"… advanced Prior overrides by parameter (pymc-marketing Prior dict form)
    controls list of string (optional) null advanced Control variables (default: every other numeric variable along time)
    lag_dim string lag advanced Lag dim of the spend tensor
    grid GridSettings {"max_multiplier": 2.0, "points": 21, "marginal_step": 0.01} advanced
    Nested settings types

    AdstockSettings¶

    Carry-over of spend into later periods.

    Field Type Default Description
    kind geometric or delayed geometric geometric: decays from the spend period; delayed: peaks after theta periods
    l_max integer (optional) null Number of lags (must equal the pipeline's lag_tensor l_max; default: taken from the data)
    normalize boolean true Normalise the lag weights to sum to one (steady-state adstock = spend)

    GridSettings¶

    Response-curve grids cached per thinned draw for Guided-mode sliders.

    Field Type Default Description
    max_multiplier number 2.0 Largest spend multiplier on the grid (1 = spend over the fit window) (> 0, ≤ 20)
    points integer 21 Grid points from 0 to max_multiplier (≥ 3, ≤ 201)
    marginal_step number 0.01 Relative spend change used for marginal cost (central difference) (> 0, ≤ 0.25)

    PositiveChannelPrior¶

    A positive prior, optionally one per channel (dims: [channel]).

    Field Type Default Description
    distribution HalfNormal or HalfStudentT or HalfCauchy or Exponential or Gamma or InverseGamma or LogNormal or Weibull or Beta or Uniform or TruncatedNormal required PyMC distribution name
    dims list of channel – max items 1

    PositiveScalarPrior¶

    A positive prior shared by every label (no dims).

    Field Type Default Description
    distribution HalfNormal or HalfStudentT or HalfCauchy or Exponential or Gamma or InverseGamma or LogNormal or Weibull or Beta or Uniform or TruncatedNormal required PyMC distribution name
    dims list of string – max items 0

    Priors¶

    Prior overrides by model parameter; unset parameters keep their defaults. Each parameter accepts only distributions with the right support (a media effect is positive, an adstock decay lies in (0, 1)) and only the dims it may vary over, so the control plane rejects a wrong prior from the JSON Schema alone.

    Field Type Default Description
    intercept RealScalarPrior (optional) null Population mean of the geo intercepts (model units: the target is mean-scaled)
    intercept_sigma PositiveScalarPrior (optional) null Spread of the geo intercepts around their population mean
    beta_channel PositiveChannelPrior (optional) null Typical (median across geos) effect of each channel at full saturation
    beta_sigma PositiveChannelPrior (optional) null Log-scale spread of a channel's effect across geos (partial pooling)
    alpha UnitChannelPrior (optional) null Adstock decay per period
    theta PositiveChannelPrior (optional) null Delayed adstock: periods until the peak effect
    lam PositiveChannelPrior (optional) null Logistic saturation rate (per unit of scaled spend)
    slope PositiveChannelPrior (optional) null Hill saturation slope
    half PositiveChannelPrior (optional) null Hill half-saturation point (scaled spend)
    gamma_control RealScalarPrior (optional) null Coefficient of each control feature (seasonality, holidays, ...)
    sigma PositiveScalarPrior (optional) null Observation noise (model units)

    RealScalarPrior¶

    A real-valued prior shared by every label (no dims).

    Field Type Default Description
    distribution Normal or StudentT or Laplace or HalfNormal or HalfStudentT or HalfCauchy or Exponential or Gamma or InverseGamma or LogNormal or Weibull or Beta or Uniform or TruncatedNormal required PyMC distribution name
    dims list of string – max items 0

    SaturationSettings¶

    Diminishing returns of (adstocked) spend.

    Field Type Default Description
    kind logistic or hill or none logistic logistic or hill curves; none for a linear response

    Field Type Default Description

    Version 1.0.0
    Inference mcmc
    Representation draws
    Score modes counterfactual, evaluate, forecast, predict
    Contributions additive
    Decision objective –
    Fast scoring –
    Owns carryover, inverse_units, scaling
    LOO valid
    Default plots core.ppc_fan, core.convergence, core.counterfactual
    Resources class M (min S)

    Outputs

    adstock_first boolean true advanced

    BootstrapUncertainty¶

    Bootstrap ensemble (representation draws, one draw per replicate). by resamples whole levels of a row dim (cluster bootstrap) instead of rows. expected outputs are the replicate predictions; predictive outputs add a resampled out-of-bag residual to each draw.

    Field Type Default Description
    kind bootstrap bootstrap
    n integer 50 ≥ 2, ≤ 1000
    by string (optional) null

    ColumnsSettings¶

    Which variables become feature columns. vars (explicit list) wins over roles; exclude removes names from either. Variables with dims beyond rows are flattened into one column per label (spend[tv], promo_lag[1]).

    Field Type Default Description
    roles list of Role – max items 16
    vars list of string (optional) null
    exclude list of string – max items 1024
