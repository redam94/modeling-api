    Built-in steps catalog¶

    Generated from the step catalog export (python -m mapi_steps.catalog and the steps of the installed plugins): the same static JSON the control plane uses to validate specs without importing step code. For how the steps behave together, read Built-in steps.

    Step Kind Learns state Invertible Looks back Summary
    core.calendar feature – – – Calendar features (day of week, month, ISO week, ...)
    core.encode_levels feature yes – – Integer codes for categorical levels
    core.formula feature – – – Derived variable from an arithmetic expression
    core.fourier feature yes – – Fourier seasonality features
    core.holidays feature – – – Holiday indicators per period from a side table
    core.lag feature – – yes Lagged copies of variables within groups
    core.lag_tensor feature – – yes Lag tensor (lags 0 .. l_max-1) for in-model carry-over
    core.missing_indicator feature – – – Indicators of missing values
    core.one_hot feature yes – – One-hot indicators of categorical variables
    core.trend feature yes – – Polynomial time trend
    dl.embed feature yes – – Image features from a frozen pretrained network
    core.count_events reshape – – – Count events per period on a dense grid
    core.filter_coords reshape – – – Select labels of a dim
    core.resample reshape – – – Aggregate a time dim to a coarser frequency
    core.stack reshape – – – Stack dims into one
    core.to_long reshape – – – Padded ragged data to long form
    core.to_padded reshape – – – Long ragged data to padded form with a mask
    core.unstack reshape – – – Unstack a dim into several
    core.adstock value – – yes Adstock (carry-over) with fixed parameters
    core.clip value – – – Clip values to bounds
    core.fx_convert value – yes – Currency conversion with per-period rates from a side table
    core.impute value yes – – Fill missing values (mean, median, constant or forward fill)
    core.log1p value – yes – log(1 + x) of the named variables
    core.logit value – yes – Logit of proportions
    core.max_abs_scale value yes yes – Divide by the maximum absolute value over the named dims
    core.mean_scale value yes yes – Divide by the mean absolute value over the named dims
    core.replace_sentinel value – – – Turn sentinel codes into missing values
    core.saturation value – – – Saturation curve with fixed parameters
    core.standardize value yes yes – Standardise to zero mean and unit variance over the named dims

    core.calendar¶

    Adds calendar facts such as the month or whether it is a weekend

    version 1.0.0 · kind feature

    - {id: my_calendar, use: core.calendar@^1, with: {...}}
    Field Type Default Description
    along string time
    features list of day_of_week or day_of_month or day_of_year or week_of_year or month or quarter or year or is_weekend or is_month_start or is_month_end required min items 1, max items 10
    out string calendar
    Schema effect template 
    {
  "template_params": [
    "out",
    "along"
  ],
  "transforms_dims": {
    "{out}_feature": {
      "kind": "categorical",
      "policy": "fixed"
    }
  },
  "adds": {
    "{out}": {
      "dims": [
        "{along}",
        "{out}_feature"
      ],
      "dtype": "float64"
    }
  }
}

    core.encode_levels¶

    Numbers each category

    version 1.0.0 · kind feature · learns state on the training data

    - {id: my_encode_levels, use: core.encode_levels@^1, with: {...}}
    Field Type Default Description
    vars list of string [] Categorical variables to encode (max items 256)
    dims list of string [] Dims whose labels to encode (max items 256)
    role covariate or index covariate
    max_levels integer 100000 ≥ 1, ≤ 1000000
    unseen_levels error or pooled or fill error error, fill (fill_code) or pooled (one shared code n_levels)
    fill_code integer -1 Code for missing values and 'fill' unseen levels
    Schema effect template 
    {
  "template_params": [
    "vars",
    "dims",
    "role"
  ],
  "derives": {
    "{*vars as v}_code": {
      "from": "{v}",
      "dtype": "int64",
      "role": "{role}",
      "missing": "forbid",
      "units": "1"
    }
  },
  "adds": {
    "{*dims as d}_code": {
      "dims": [
        "{d}"
      ],
      "dtype": "int64",
      "role": "{role}"
    }
  }
}

    "out",

    "by"
  ],

      "dims": [

    core.lag¶

    Adds last period's (or earlier) values as extra columns

    version 1.0.0 · kind feature · depends on the target (recursive at forecast time)

    - {id: my_lag, use: core.lag@^1, with: {...}}
    Field Type Default Description
    vars list of string required min items 1, max items 256
    along string time
    within list of string [] Group dims (dense) or row group variables (long) (max items 256)
    mask string (optional) null Boolean variable; cells where it is False count as missing
    lags list of integer required min items 1, max items 64
    lag_dim string lag
    fill number (optional) null Value for lags with no history (default NaN)

    Context need (per group, stored at fit): {"along": "{along}", "n": "{max:lags}", "within": "{within}", "min_lag": "{min:lags}"}

    Schema effect template 
    {
  "template_params": [
    "vars",
    "lag_dim"
  ],
  "transforms_dims": {
    "{lag_dim}": {
      "kind": "integer",
      "policy": "fixed"
    }
  },
  "derives": {
    "{*vars as v}_lagged": {
      "from": "{v}",
      "append_dims": [
        "{lag_dim}"
      ],
      "dtype": "float64",
      "role": "covariate",
      "missing": "allow"
    }
  }
}

    core.count_events¶

    Turns a list of events into counts per day, week or month

    version 1.0.0 · kind reshape

    - {id: my_count_events, use: core.count_events@^1, with: {...}}
    Field Type Default Description
    along string event Row dim of the event table
    time_var string timestamp Datetime variable along the rows
    freq string required Period length of the counts, e.g. 'D' or 'W-SUN'
    dim string time Name of the new time dim
    by list of string [] Row variables that become dims (max items 256)
    sum_vars list of string [] Numeric row variables summed per period (max items 256)
    out string count
    levels map of list of string {} Pinned levels per by variable (default: observed)
    start string (optional) null Earliest event time kept (ISO); the grid starts at its period
    end string (optional) null Latest event time kept (ISO); the grid ends at its period

    "time_var",
    "by",
    "sum_vars",
    "dim",
    "freq",

    "{time_var}",
    "{*by}",
    "{*sum_vars}",
    "{along}"
  ],
  "transforms_dims": {
    "{dim}": {
      "kind": "time",
      "policy": "extend",
      "freq": "{freq}"
    },
    "{*by as b}": {
      "kind": "categorical",
      "policy": "fixed"
    }
  },
  "adds": {
    "{out}": {
      "dims": [
        "{*by}",
        "{dim}"
      ],
      "dtype": "float64",
      "units": "1"
    },
    "{*sum_vars as v}": {
      "dims": [
        "{*by}",
        "{dim}"
      ],
      "dtype": "float64"
    }
  }
}

    Field Type Default Description
    row_dim string obs
    group string required Variable along the rows naming each row's group
    group_dim string required Name of the outer dim (existing or new)
    within_dim string required Name of the new position dim
    vars list of string required Every other variable on the rows (min items 1, max items 256)
    mask_var string mask Name of the boolean validity mask to add
    group_policy DimPolicy fixed
    Schema effect template 
    {
  "template_params": [
    "row_dim",
    "group",
    "group_dim",
    "within_dim",
    "vars",
    "mask_var",
    "group_policy"
  ],
  "renames": {
    "{row_dim}": "{within_dim}"
  },
  "drops": [
    "{group}"

    Field Type Default Description
