    Entry-point groups¶

    A plugin distribution registers its objects through these groups in its pyproject.toml ([project.entry-points."<group>"]). Each entry point names one module attribute, so a broken model never hides your plots or workflow nodes. mapi plugin validate and mapi plugin doctor read the same groups.

    Group One entry point exports Id Contract kit mapi plugin init --kind
    mapi.models a model class or a list of them (CustomModel, PyMCModel, SklearnModel) <ns>.<name> mapi_sdk.testing.check_model model (--base custom, pymc or sklearn)
    mapi.steps a Step class or a list of them <ns>.<name> mapi_sdk.testing.check_step step
    mapi.plots a @recipe function or a list of them <ns>.<name> mapi_plots.testing.check_recipe recipe
    mapi.workflow_nodes a NodeExport(contract, fn) or a list of them (a {id: fn} dict is deprecated) <kind>.<ns>_<name>, contract.plugin == ns mapi_workflows.kit.check_node node
    mapi.workflow_templates a TemplateCatalogEntry or a list of them <ns>_<name> mapi_workflows.kit.check_template template
    mapi.governance_checks a mapping of check id to runner (operators; no scaffold) a GOVERNANCE_CHECKS id - -

    Namespaces¶

    Every id lives in one namespace: <ns>.<name> for models, steps and recipes, <kind>.<ns>_<name> for workflow nodes (with contract.plugin = "<ns>") and <ns>_<name> for workflow templates. A third-party plugin may not use these namespaces (mapi_spec.namespaces):

    • Built-in (only the distributions that ship with the platform): causal, choice, core, demo, dl, examples, ml, mmm, net, sci, sklearn, tabular, toy, ts.
    • Reserved for the platform (library items, uploads): builtin, lib, library, mapi, platform, plugin, t, team, tenant, and every namespace that starts with t_, tenant_.
    • Built-in distributions: mapi-conformance, mapi-jax, mapi-plots, mapi-plugin-causal, mapi-plugin-mmm, mapi-plugin-science, mapi-plugin-statsmodels, mapi-plugin-tabular, mapi-plugin-ts, mapi-pymc, mapi-runner, mapi-sdk, mapi-sklearn, mapi-steps, mapi-workflows. The catalog sets provider (the distribution name) on every entry of any other distribution; the app shows it as "Installed by your team".

    Workflow nodes¶

    • Kinds a plugin node may have: evaluate, governance, plot, report, search, split, test, transform. Never branch, compare, select, model or subworkflow (they run in the control plane or start fits).
    • runs_in is sandbox. The runner refuses a job whose node version is not the version of the installed contract (NODE_UNKNOWN).
    • Port types: dataset, evidence, metrics, model_version, plot, report, split_plan, table, test_result.

    Settings and parameter schemas¶

    The control plane checks every JSON Schema that a plugin publishes before a form is made from it (mapi_spec.schema_safety). Built-in and installed catalogs are stripped (an unsafe keyword is removed, with a schema_unsafe diagnostic); library documents are refused.

    Limit Value
    Size of a schema 65,536 B
    Size of a plot settings_schema after sanitizing 16,384 B
    Depth 12
    Properties 256
    enum items 64 of at most 200 characters
    title, description plain text, at most 2000 characters
    pattern at most 256 characters; no back-references, look-arounds, possessive or atomic groups, nested quantifiers or alternation inside a quantified group; {m,n} with n at most 1000
    format date, date-time
    $ref local #/$defs/... only, no cycles
    x-ui-widget checkbox, dim_picker, select, slider, textarea, var_picker
    Other x-ui-* keywords x-ui-group, x-ui-level, x-ui-order

    Catalog diagnostics¶

    What the runner could not put into the catalog, or put there with a change. Tenant admins see them in Catalog > Yours > Problems and through GET /v1/catalog/diagnostics; mapi plugin doctor prints them. At most 500 in all and 20 for each distribution.

    Code Meaning
    load_error An entry point or one of its objects could not be imported or registered.
    namespace_reserved The id uses a built-in or platform namespace.
    id_collision The id and version are already registered; the first one stays.
    schema_unsafe A settings or parameter schema had a keyword the platform removes.
    about_incomplete The About card misses a field that the catalog shows.
    node_contract_invalid A workflow node contract breaks a plugin rule.
    template_invalid A workflow template does not validate against the known nodes.
    deprecated The export uses an old form that still works (for example {id: fn}).

    Library documents (no code)¶

    The four kinds an analyst makes in Make your own. Each is a JSON (or YAML) document that pure mapi_spec code compiles to things the platform already runs.

    Kind Document kind Lineage label on what it makes
    Model recipe ModelRecipe mapi.library/model
    Prep preset PrepPreset mapi.library/prep
    Chart template ChartTemplate the plot's provenance.author
    Workflow template WorkflowTemplate mapi.library/template
    • Document size: at most 262,144 B; a chart template's Vega-Lite spec at most 65,536 B.
    • Items per tenant: 500; revisions per item: 200.
    • A declarative model recipe compiles to tabular.declarative_glm@^1. Outcome families: bernoulli, beta, gamma, negative_binomial, normal, ordinal, poisson, student_t, zero_inflated_negative_binomial, zero_inflated_poisson. Priors: exponential, half_normal, laplace, lognormal, normal, student_t. Signs: any, positive, negative. Transforms: adstock, impute, log1p, max_abs_scale, mean_scale, saturation, standardize. At most 3 groups, 16 interactions and 64 terms.
    • A prep preset slot is a whole value "$slot:<name>" (or an item of a list). Slot kinds: var, var_list, dim. A core.formula expression has at most 4000 printable ASCII characters; the sandbox parses it when the model is fitted.

    Uploaded plugins¶

    v0.19. A tenant admin or a confirmed uploader uploads a pure-Python wheel (Upload your own code); a second tenant admin approves it (Review uploaded code). Generated from mapi_spec.plugins and mapi_spec.api.V019_ENDPOINTS.

    Namespaces and ids¶

    • Namespace: t_<tenant code>_<short name>, pattern ^t_([a-z2-7]{6})_([a-z][a-z0-9]{1,15})$. Tenant code ^[a-z2-7]{6}$ (given by the platform); short name ^[a-z][a-z0-9]{1,15}$ (no underscore).
    • Ids: <ns>.<name> for models, steps and plot recipes, <kind>.<ns>_<name> for workflow nodes and <ns>_<name> for workflow templates.
    • Distribution name: the namespace with dashes (t-k3vq7m-acme); one top-level package named the namespace.
    • Entry-point groups an upload may use: mapi.models, mapi.plots, mapi.steps, mapi.workflow_nodes, mapi.workflow_templates.
    • Overlays mounted in one run: at most 8.

    Version states¶

    State Meaning Next states
    uploaded The file is stored and hashed. inspecting
    inspecting The file check (plugin_inspect) runs. describing, inspect_failed
    inspect_failed The file check found problems. The version is refused. purged
    describing The test run (plugin_describe) runs. kit_failed, kit_passed
    kit_failed A test or a check of the exports failed. purged
    kit_passed (can run) The checks passed. The uploader can use it (private use). awaiting_approval, yanked
    awaiting_approval (can run) The uploader asked for a review. The uploader can still use it. approved, rejected, yanked
    approved (can run) A second tenant admin approved it. The tenant can use it. awaiting_approval, yanked
    rejected A tenant admin did not approve it. purged
    yanked Withdrawn. No new run can use it. purged
    purged The file is deleted. The row and the audit log stay. -

    Archive limits¶

    Defaults; the operator changes them with the settings in Uploaded code.

    Limit Value
    Wheel size 20,971,520 B
    Total size after decompression 104,857,600 B
    One file after decompression 20,971,520 B
    Files 2,000
    Compression ratio 100
    Path depth 16
    Path length 255 characters
    describe.json 2,097,152 B
    inspection.json 1,048,576 B

    File checks¶

    plugin_inspect reads the wheel as an archive and imports nothing. Each problem has one of these check values (InspectProblem.check).

    Check The wheel is refused when
    archive_size The wheel, or its total size after decompression, is too large.
    member_count The wheel has too many files.
    member_size One file is too large after decompression.
    ratio A file, or the wheel, expands too much (a zip bomb).
    path_unsafe A file name is absolute, has .., a backslash, NUL or is too long or deep.
    link_member An entry is a symbolic link.
    special_member An entry is a device, pipe or socket.
    duplicate_name Two entries have the same name.
    case_collision Two names differ only in case.
    zip_structure The zip structure is not correct (overlaps, bad headers, data before the first entry, ZIP64 not necessary).
    encrypted A file is encrypted.
    compression_method A file uses a compression method other than stored or deflate.
    nested_archive The wheel holds another archive.
    native_code The wheel holds compiled native code (by name or by magic bytes).
    bytecode The wheel holds compiled Python bytecode or __pycache__.
    pth_file The wheel holds a .pth file.
    site_hook The wheel holds sitecustomize, usercustomize, an .egg-link or a top-level __main__.py.
    top_level_name The wheel has a top-level name other than the namespace package, or the package hides a package of the base image.
    namespace_package The namespace package has no __init__.py.
    dist_name The distribution name is not the namespace with dashes, or is the name of a package of the base image.
    dist_info The .dist-info directory is missing, doubled or misnamed, or a metadata file is missing.
    wheel_tag The WHEEL file is not for pure Python 3 (py3-none-any, Root-Is-Purelib: true).
    data_dir The wheel has a .data directory.
    entry_point_group An entry point group is not allowed, or there is no entry point.
    entry_point_target An entry point target is not module:attribute in the namespace package.
    requirement_unlocked A requirement is not installed in the base image, or not in a version that fits.
    requirement_url A requirement is a URL or a path.
    requires_python Requires-Python excludes the Python of the base image.
    metadata_invalid METADATA or entry_points.txt cannot be read, or the version is not the uploaded version.
    text_unsafe A name has invisible, control or direction-changing characters.
    sha_mismatch The file is not the file that was uploaded (sha256).

    Routes¶

    Method Path Success Errors Summary
    GET /v1/plugins 200 - Uploaded plugins of the tenant (private versions of other people are hidden)
    POST /v1/plugins 201 SCHEMA_INVALID, FORBIDDEN, IDENTITY_VERIFICATION_REQUIRED, PLUGIN_NAMESPACE_TAKEN, PAYLOAD_TOO_LARGE Claim a short name for uploaded code: the namespace is t_<tenant code>_<short name> (the tenant code is assigned on the first claim)
    GET /v1/plugins/{plugin_id} 200 NOT_FOUND One uploaded plugin and its latest version
    GET /v1/plugins/{plugin_id}/versions 200 NOT_FOUND The versions of an uploaded plugin, newest first (private versions only for the uploader and tenant admins)
    GET /v1/plugins/{plugin_id}/versions/{version_id} 200 NOT_FOUND One version: inspect facts, SBOM, kit report, exports, decisions (ETag)
    POST /v1/plugins/{plugin_id}/uploads 201 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN, IDENTITY_VERIFICATION_REQUIRED, PAYLOAD_TOO_LARGE, RATE_LIMITED Get an upload ticket: a POST policy for one wheel in the quarantine bucket (at most 20 per user per day)
    POST /v1/plugins/{plugin_id}/uploads/{upload_id}:complete 202 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN, IDENTITY_VERIFICATION_REQUIRED, PLUGIN_REFUSED, PLUGIN_VERSION_EXISTS, PRECONDITION_FAILED, UNTRUSTED_PLACEMENT_UNAVAILABLE, PAYLOAD_TOO_LARGE The wheel is uploaded: hash it and start the checks (202, state inspecting)
    POST /v1/plugins/{plugin_id}/versions/{version_id}:request-approval 200 NOT_FOUND, FORBIDDEN, PLUGIN_STATE_CONFLICT Ask the tenant admins to review a version that passed its tests
    POST /v1/plugins/{plugin_id}/versions/{version_id}:approve 200 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN, SELF_APPROVAL_FORBIDDEN, PLUGIN_STATE_CONFLICT, REAUTH_REQUIRED Approve a version for the whole tenant (a second tenant admin, signed in to the web app in the last 15 minutes; the body repeats the digests the page showed)
    POST /v1/plugins/{plugin_id}/versions/{version_id}:reject 200 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN, SELF_APPROVAL_FORBIDDEN, PLUGIN_STATE_CONFLICT, REAUTH_REQUIRED Reject a version (same rules as approve; a note is required)
    POST /v1/plugins/{plugin_id}/versions/{version_id}:yank 200 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN, PLUGIN_STATE_CONFLICT Withdraw a version (its uploader or a tenant admin, web session only); 'security' also cancels the queued and running runs that use it
    GET /v1/plugins/{plugin_id}/versions/{version_id}/usage 200 NOT_FOUND What uses a version: runs in the last 30 days, model versions, endpoints and dashboards
    GET /v1/plugins/{plugin_id}/versions/{version_id}/examples/{plot_id} 200 NOT_FOUND The example of an uploaded plot recipe (a re-sanitized PlotSpec)
    GET /v1/tenants/{tenant_id}/plugin-settings 200 NOT_FOUND, FORBIDDEN The tenant's uploaded-code settings and whether uploads are allowed (tenant admins)
    PATCH /v1/tenants/{tenant_id}/plugin-settings 200 NOT_FOUND, SCHEMA_INVALID, FORBIDDEN Turn private use of uploads that passed their tests on or off (tenant admins)
    GET /v1/tenants/{tenant_id}/plugin-uploaders 200 NOT_FOUND, FORBIDDEN Editors a tenant admin attested for uploads (tenant admins)
    PUT /v1/tenants/{tenant_id}/plugin-uploaders/{user_id} 200 NOT_FOUND, FORBIDDEN, CONFLICT Attest that you know who this editor is: they may upload code (tenant admins, web session only; not yourself)
    DELETE /v1/tenants/{tenant_id}/plugin-uploaders/{user_id} 204 NOT_FOUND, FORBIDDEN Revoke an attestation (tenant admins, web session only)

    Error codes¶

    Plugin code can never raise these codes itself.

    Code Status Title
    PLUGIN_NAMESPACE_TAKEN 409 The plugin name is already used in this workspace
    PLUGIN_REFUSED 422 The uploaded package was refused
    PLUGIN_STATE_CONFLICT 409 The plugin version is not in a state that allows this
    PLUGIN_UNAVAILABLE 409 An uploaded plugin that the item needs is not available to you
    PLUGIN_VERSION_EXISTS 409 This version of the plugin was already uploaded
    REAUTH_REQUIRED 401 Sign in again to do this
    UNTRUSTED_PLACEMENT_UNAVAILABLE 409 No executor in this deployment can run uploaded code
    UPLOADED_CODE_NOT_SHAREABLE 403 Results made with uploaded code cannot be shared outside the workspace
