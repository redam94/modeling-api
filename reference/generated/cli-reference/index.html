    CLI reference¶

    Every mapi command with its --help, generated from the installed CLI by scripts/gen_docs_reference.py. The command-line guide shows them in use. Global options (--url, --token, --profile, --json) go before the command: mapi --json runs ls.

    Command What it does
    mapi new Scaffold a ModelSpec YAML from a template (geo-mmm, forecast, tabular, glm).
    mapi check Statically validate a spec (exit status 1 when it has errors).
    mapi fit Fit a spec locally (in-process) or on the API (--remote).
    mapi score Score a fitted bundle locally, or a model version on the API (--remote).
    mapi catalog Show the catalog of the locally installed plugins (or the API's with --remote).
    mapi login Sign in to the API (browser OIDC, device code, or an API token).
    mapi logout Forget the stored sign-in and API token of the profile.
    mapi whoami Who you are, how you are signed in, and the projects you can use.
    mapi use Select the project commands act in (sent as X-Mapi-Project), or show it.
    mapi usage Cost and quota use of the selected project (or --tenant) for a UTC day or month.
    mapi signup Create a workspace: sends a verification e-mail (valid 24 hours).
    mapi verify-email Redeem a verification token: creates your workspace and its default project.
    mapi serve Start the local development stack (API, embedded Postgres, GCS shim).
    mapi approve Approve (or --reject) a validated model version as a reviewer.
    mapi optimize Split a marketing budget across channels with a fitted marketing-mix model.
    mapi choose Help me choose: a few questions about your goal and data, then the best fits.
    mapi about The About card of anything a user can pick: what it does in plain words, when to use it and when not, what it needs, assumes and gives.
    mapi runs Inspect and control runs on the API.
    mapi runs ls List runs, newest first.
    mapi runs get Show one run (state, failure, cost, problem).
    mapi runs logs Print captured log lines (untrusted text, control characters stripped).
    mapi runs watch Follow a run's live events until it ends (--json: one JSON event per line).
    mapi runs cancel Request cancellation (idempotent).
    mapi runs retry Start a new run from a failed one (e.g. one resource class up).
    mapi datasets Datasets on the API.
    mapi datasets ls List datasets.
    mapi datasets upload Upload a file as a new dataset version (signed PUT + sandboxed ingest run).
    mapi plugin Plugin authoring: scaffold and test model plugins.
    mapi plugin init Scaffold a plugin package (model, entry point and contract-kit tests).
    mapi plugin test Run the plugin's tests (contract kit) with this interpreter; extra args go to pytest.
    mapi spec Spec document tools.
    mapi spec upgrade Upgrade a document through the registered converters (N-1 → N).
    mapi config Client configuration (~/.config/mapi/config.toml).
    mapi config show Resolved settings and where each came from (secrets are never shown).
    mapi config path Print the config file location.
    mapi config set Set a key of the profile (--profile, MAPI_PROFILE, else the default profile).
    mapi config unset Remove a key from the profile (token too: prefer mapi logout).
    mapi tokens API tokens of the selected project (secrets are shown once, at creation).
    mapi tokens ls List tokens (yours, or everyone's with --all).
    mapi tokens get Show one token (never its secret).
    mapi tokens create Mint a token in the selected project. Its secret is shown once.
    mapi tokens revoke Revoke a token: programs using it stop working at once.
    mapi admin Platform operator commands: tenants, quotas, kill switches, executors, audit.
    mapi admin audit The platform audit log, newest first (times in UTC).
    mapi admin tenants All tenants (create, change tier/status/residency).
    mapi admin tenants ls List all tenants.
    mapi admin tenants get Show one tenant.
    mapi admin tenants create Create a tenant.
    mapi admin tenants update Change a tenant's name, trust tier, status or data residency.
    mapi admin quotas Quota policies per token, tenant or the platform.
    mapi admin quotas ls List quota policies.
    mapi admin quotas set Create or REPLACE the policy of (scope, subject): limits left out are removed.
    mapi admin quotas rm Remove a policy (the tier default applies again).
    mapi admin kill-switches Platform-wide emergency controls (audited).
    mapi admin kill-switches get Show the kill switches.
    mapi admin kill-switches set Flip kill switches (confirmation shows the change; the server audits it).
    mapi admin executors Executor health, capacity and conformance.
    mapi admin executors ls Executor health, load and conformance.
    mapi admin executors get One executor.
    mapi admin executors disable Disable an executor: no new run is placed on it (incident containment).
    mapi admin executors enable Enable an executor again.
    mapi endpoints Endpoints: stable aliases for promoted model versions (promote, score, snippets).
    mapi endpoints ls List the project's endpoints.
    mapi endpoints get Show an endpoint, the version it serves and its promotion gate.
    mapi endpoints history Promotions and rollbacks, newest first.
    mapi endpoints promote Point an alias at a model version, through the scorecard promotion gate.
    mapi endpoints rollback Point the alias back at an earlier revision's version.
    mapi endpoints schema What to send: the input schema frozen at promotion and an example payload.
    mapi endpoints score Score the endpoint's current version and wait for the result.
    mapi endpoints snippets Ready-to-run code that scores the endpoint (reads the token from MAPI_TOKEN).
    mapi webhooks Webhooks of the selected project (secrets are shown once, at creation).
    mapi webhooks ls List webhooks (never their secrets).
    mapi webhooks get Show one webhook (never its secret).
    mapi webhooks create Add a webhook. Its signing secret is printed once.
    mapi webhooks update Change a webhook: switch it back on after it was paused or disabled automatically, or change its events, URL or description. The secret is unchanged.
    mapi webhooks rotate New signing secret (printed once); the current one keeps signing for 24 hours.
    mapi webhooks deliveries The delivery log, newest first.
    mapi webhooks replay Send a delivery's event again (a new delivery).
    mapi webhooks rm Delete a webhook and its delivery log.
    mapi plots Render plots to files and share them as embed links.
    mapi plots render Render one plot to a PNG, SVG or PDF file.
    mapi plots embed Create a read-only embed link for a saved plot. Its URL is printed once.
    mapi plots embeds List a saved plot's embed links (redacted).
    mapi plots revoke Revoke an embed link: dashboards showing it stop at once.
    mapi guided Guided mode: templates, column detection and drafts (stores nothing).
    mapi guided templates List the guided templates, or one template's questions.
    mapi guided detect Suggest which column answers each question of a template.
    mapi guided draft Answers -> the ingest mapping and the ModelSpec YAML (nothing is stored).
    mapi priors Business priors: translate beliefs into model priors.
    mapi priors preview Translate beliefs into priors in the sandbox and preview them.
    mapi tenant Your workspace (tenant): verification status, GDPR export and deletion.
    mapi tenant status Verification (e-mail, identity, code upload) and any deletion of the tenant.
    mapi tenant export GDPR export: everything the tenant stored, as one zip archive.
    mapi tenant delete Schedule deletion of the whole tenant (cancellable during the grace period).
    mapi workflows Workflows: validate, save, run and watch DAGs of tests, transforms and models.
    mapi workflows validate Check a workflow file on the server (nothing is saved): unknown nodes, parameters, ports, conditions and cycles, each with a JSON pointer.
    mapi workflows apply Create the workflow named in the file, or save the file as its next revision (an unchanged file adds nothing).
    mapi workflows create Create a workflow from a file or a gallery template (revision 1).
    mapi workflows ls List the project's workflows.
    mapi workflows get Show a workflow (and with --yaml its document at the latest or a given revision).
    mapi workflows revisions Revisions, newest first, and whether each can run.
    mapi workflows archive Archive a workflow (it can no longer run) or bring it back with --undo.
    mapi workflows rm Delete a workflow with its runs, schedules and triggers.
    mapi workflows templates The gallery of ready-made workflows, each in plain words.
    mapi workflows template One template's About card and its nodes.
    mapi workflows init Write a gallery template as a YAML file to edit, validate and apply.
    mapi workflows run Start a run (inputs are pinned to exact versions when it starts).
    mapi workflows watch Follow a run live: every node's status, branch decisions, then the summary (--json: one JSON event per line).
    mapi workflows status A run's status, nodes, decisions and outputs.
    mapi workflows runs Runs of a workflow, newest first.
    mapi workflows nodes The nodes of a run with what each found.
    mapi workflows node One node in full: resolved parameters, result, outputs and child runs.
    mapi workflows output Download a node output's file (a derived dataset, a fitted bundle), verified.
    mapi workflows cancel Cancel a run and its running children.
    mapi workflows nodes-catalog The node implementations a workflow can use, in plain words.
    mapi workflows schedules Cron schedules of a workflow.
    mapi workflows schedules ls A workflow's schedules.
    mapi workflows schedules add Run the workflow on a schedule (at most every 15 minutes).
    mapi workflows schedules pause Pause a schedule.
    mapi workflows schedules resume Resume a paused schedule.
    mapi workflows schedules rm Delete a schedule.
    mapi workflows triggers Run a workflow when a dataset gets a new version.
    mapi workflows triggers ls A workflow's dataset triggers.
    mapi workflows triggers add Run the workflow whenever the dataset gets a new version.
    mapi workflows triggers rm Delete a trigger.
    mapi governance Governance: the check catalog and the policies models must pass.
    mapi governance checks The checks a policy can require, in plain words.
    mapi governance policies Project and tenant-wide governance policies.
    mapi governance policies ls Policies in force in the project (tenant-wide first), or a tenant's.
    mapi governance policies get A policy's latest version with every check and threshold.
    mapi governance policies create Add a policy from a file (name, applies_to, checks, require_approval, ...).
    mapi governance policies update Save the file as the policy's next version.
    mapi governance policies retire Retire a policy (its versions stay for audit).
    mapi governance policies versions Every version of a project policy, newest first.
    mapi validate Validate a model version against the governance policies (or a workflow file).
    mapi validate model Run the governance checks on a model version and show every result.
    mapi validate workflow Check a workflow file on the server (same as mapi workflows validate).
    mapi validations Validations: the review queue, evidence, resubmission, deprecation, evidence packs.
    mapi validations ls Validations of the project, most recently changed first.
    mapi validations get A validation: status, every result, approvals and history.
    mapi validations evidence Every check result with its evidence (numbers, tables).
    mapi validations cancel Stop running checks (back to draft).
    mapi validations resubmit Run the checks again after a failure or a rejection.
    mapi validations deprecate Retire a validated model version (audited with the reason).
    mapi validations pack Export the evidence pack for an auditor (self-contained HTML, or JSON).
    mapi explore Explore a dataset or a model (sections computed in the sandbox), compare models.
    mapi explore dataset Explore a dataset version: profile, distributions, time plots, missingness, outliers, correlations, cross-correlation with the KPI, ACF/PACF, stationarity, STL, VIF, group comparisons and data-quality warnings.
    mapi explore model Explore a model version: parameters, diagnostics, fit vs actual, residual tests, decomposition, response curves, IRF/FEVD, forecasts, backtests and comparisons.
    mapi explore compare Compare model versions on their shared holdout: metrics, ranking and pairwise Diebold-Mariano tests (is the difference more than luck?).
    mapi explore get An exploration's sections (and with --out its views).

    mapi¶

    Usage: mapi [OPTIONS] COMMAND [ARGS]...

  The modeling-api command line.

  Local commands (new, check, fit, score, catalog, plugin, spec) need no server. Remote commands
  (runs, datasets, tokens, usage, admin, endpoints, webhooks, plots, guided, priors, tenant,
  signup, workflows, governance, validate, validations, approve, explore, optimize, choose,
  about, --remote) use the API from --url, MAPI_URL or a profile in ~/.config/mapi/config.toml,
  signed in with `mapi login` (or --token / MAPI_TOKEN), in the project chosen with `mapi use`
  (or --project / MAPI_PROJECT). --json prints machine-readable output on stdout.

Options:
  --url <str>           API base URL (default: MAPI_URL, profile, local)
  --token <str>         Bearer token (default: MAPI_TOKEN, profile)
  --profile <str>       Config profile (default: MAPI_PROFILE)
  --project <str>       <tenant>/<project> to act in (default: MAPI_PROJECT, mapi use)
  --json                Machine-readable JSON on stdout
  --version             Show the version
  --install-completion  Install completion for the current shell.
  --show-completion     Show completion for the current shell, to copy it or customize the
                        installation.
  -h, --help            Show this message and exit.

    mapi new¶

    Usage: mapi new [OPTIONS] [template]

  Scaffold a ModelSpec YAML from a template (geo-mmm, forecast, tabular, glm).

Arguments:
  template  One of: geo-mmm, forecast, tabular, glm

Options:
  -o, --output <path>  Spec file to write (default: spec.yaml)
