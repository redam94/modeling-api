    CLI reference¶

    Every mapi command with its --help, generated from the installed CLI by scripts/gen_docs_reference.py. The command-line guide shows them in use. Global options (--url, --token, --profile, --json) go before the command: mapi --json runs ls.

    Command What it does
    mapi new Scaffold a ModelSpec YAML from a template (geo-mmm, forecast, tabular, glm).
    mapi check Statically validate a spec (exit status 1 when it has errors).
    mapi fit Fit a spec locally (in-process) or on the API (--remote).
    mapi score Score a fitted bundle locally, or a model version on the API (--remote).
    mapi catalog Show the catalog of the locally installed plugins (or the API's with --remote).
    mapi serve Start the local development stack (API, embedded Postgres, GCS shim).
    mapi runs Inspect and control runs on the API.
    mapi runs ls List runs, newest first.
    mapi runs get Show one run (state, failure, progress, problem).
    mapi runs logs Print captured log lines (untrusted text, control characters stripped).
    mapi runs watch Follow a run's live events until it ends (--json: one JSON event per line).
    mapi runs cancel Request cancellation (idempotent).
    mapi runs retry Start a new run from a failed one (e.g. one resource class up).
    mapi datasets Datasets on the API.
    mapi datasets ls List datasets.
    mapi datasets upload Upload a file as a new dataset version (signed PUT + sandboxed ingest run).
    mapi plugin Plugin authoring: scaffold and test model plugins.
    mapi plugin init Scaffold a plugin package (model, entry point and contract-kit tests).
    mapi plugin test Run the plugin's tests (contract kit) with this interpreter; extra args go to pytest.
    mapi spec Spec document tools.
    mapi spec upgrade Upgrade a document through the registered converters (N-1 → N).
    mapi config Client configuration (~/.config/mapi/config.toml).
    mapi config show Resolved URL, profile and where each value came from (the token is never shown).
    mapi config path Print the config file location.

    mapi¶

    Usage: mapi [OPTIONS] COMMAND [ARGS]...

  The modeling-api command line.

  Local commands (new, check, fit, score, catalog, plugin, spec) need no server. Remote commands
  (runs, datasets, --remote) use the API from --url, MAPI_URL or a profile in
  ~/.config/mapi/config.toml, with --token or MAPI_TOKEN. --json prints machine-readable output
  on stdout.

Options:
  --url <str>           API base URL (default: MAPI_URL, profile, local)
  --token <str>         Bearer token (default: MAPI_TOKEN, profile)
  --profile <str>       Config profile (default: MAPI_PROFILE)
  --json                Machine-readable JSON on stdout
  --version             Show the version
  --install-completion  Install completion for the current shell.
  --show-completion     Show completion for the current shell, to copy it or customize the
                        installation.
  -h, --help            Show this message and exit.

Commands:
  new       Scaffold a ModelSpec YAML from a template (geo-mmm, forecast, tabular, glm).
  check     Statically validate a spec (exit status 1 when it has errors).
  fit       Fit a spec locally (in-process) or on the API (--remote).
  score     Score a fitted bundle locally, or a model version on the API (--remote).
  catalog   Show the catalog of the locally installed plugins (or the API's with --remote).
  serve     Start the local development stack (API, embedded Postgres, GCS shim).
  runs      Inspect and control runs on the API.
  datasets  Datasets on the API.
  plugin    Plugin authoring: scaffold and test model plugins.
  spec      Spec document tools.
  config    Client configuration (~/.config/mapi/config.toml).

    mapi new¶

    Usage: mapi new [OPTIONS] [template]

  Scaffold a ModelSpec YAML from a template (geo-mmm, forecast, tabular, glm).

Arguments:
  template  One of: geo-mmm, forecast, tabular, glm

Options:
  -o, --output <path>  Spec file to write (default: spec.yaml)
  --name <str>         metadata.name (default: the template name)
  --project <str>      metadata.project  [default: default]
  --with-data          Also write the fixture's tiny sample data (zarr zips)
  --force              Overwrite existing files
  --list               List the templates
  -h, --help           Show this message and exit.

    mapi check¶

    Usage: mapi check [OPTIONS] {spec_file}

  Statically validate a spec (exit status 1 when it has errors).

Arguments:
  spec_file  ModelSpec YAML/JSON  [required]

Options:
  --data <path>    Dataset (.zarr.zip) giving the raw schema
  --schema <path>  Raw DataSchema (JSON/YAML) instead of data
  --stages         Show the schema at every stage
  --remote <str>   Validate on the API at this URL ('@' = configured URL)
  --dataset <str>  (remote) dataset ref overriding data.dataset
  -h, --help       Show this message and exit.

    mapi fit¶

    Usage: mapi fit [OPTIONS] {spec_file}

  Fit a spec locally (in-process) or on the API (--remote).

Arguments:
  spec_file  ModelSpec YAML  [required]

Options:
  --data <path>                Fit data (.zarr.zip); required locally
  --side-table <str>           NAME=PATH for each data.side_tables entry
  --schema <path>              Raw DataSchema (JSON/YAML) of --data
  --out <path>                 Bundle directory (default: bundles/<name>)
  --remote <str>               Fit on the API at this URL ('@' = configured URL)
  --resource-class <S|M|L|XL>  (remote) S, M, L or XL
  --wait / --no-wait           (remote) follow the run  [default: wait]
  --timeout <float>            (local) give up after N seconds
  -h, --help                   Show this message and exit.

    mapi score¶

    Usage: mapi score [OPTIONS] {request}

  Score a fitted bundle locally, or a model version on the API (--remote).

Arguments:
  request  ScoreRequest YAML  [required]

Options:
  --bundle <path>     (local) bundle directory from 'mapi fit'
  --data <path>       (local) data payload
  --scenario <path>   (local) scenario payload
  --side-table <str>  (local) NAME=PATH
  -o, --out <path>    Write the result DataTree (.zarr.zip)
  --remote <str>      Score on the API ('@' = configured URL)
  --model <str>       (remote) model id
  --version <int>     (remote) version
  --wait <int range>  (remote) Prefer: wait=N seconds  [default: 60; 0<=x<=60]
  --timeout <float>   Give up after N seconds
  -h, --help          Show this message and exit.

  -h, --help      Show this message and exit.

    mapi runs ls¶

    Usage: mapi runs ls [OPTIONS]

  List runs, newest first.

Options:
  --kind <ingest|describe|validate|fit|score|evaluate|derive|render|optimize|sweep|backtest|sbc|campaign>
                                  Filter by kind
  --state <created|rejected|queued|dispatching|provisioning|running|stalled|finalizing|succeeded|partial|failed|cancelling|cancelled>
                                  Filter by state
  --spec <str>                    Filter by spec id
  -n, --limit <int range>         At most N runs  [default: 20; x>=1]
  -h, --help                      Show this message and exit.

    mapi datasets upload¶

    Usage: mapi datasets upload [OPTIONS] {file}

  Upload a file as a new dataset version (signed PUT + sandboxed ingest run).

Arguments:
  file  .zarr.zip, .nc, .csv or .parquet  [required]

Options:

  --mapping <path>     IngestMapping YAML/JSON (required for csv/parquet)

  --wait / --no-wait   Wait for the ingest run  [default: wait]
  --timeout <float>
  -h, --help           Show this message and exit.

    mapi spec upgrade¶

    Usage: mapi spec upgrade [OPTIONS] {spec_file}

  Upgrade a document through the registered converters (N-1 → N).

  The result is re-validated as a typed document. Comments are not preserved when the document
  changes (it is re-serialised as canonical YAML).

Arguments:
  spec_file  Spec YAML/JSON  [required]

Options:
  --to <str>           Target apiVersion  [default: mapi/v1]
  -o, --output <path>  Write here (default: stdout)
  --in-place           Rewrite the file
  --check              Only report whether an upgrade is needed (exit 1)
  -h, --help           Show this message and exit.
