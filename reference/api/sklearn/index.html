    mapi_sklearn¶

    This package is for scikit-learn and xgboost models. You write estimator(). The package gives stacking, safe persistence and uncertainty.

    Base classes¶

    SklearnModel: scikit-learn and xgboost estimators on labelled data (plan §5).

    A plugin author implements only :meth:SklearnModel.estimator, returning an allow-listed estimator (a choice from :data:~mapi_sklearn.estimators.ESTIMATORS, a {kind, params} mapping, or an instance of an allow-listed class). The platform:

    1. stacks the rows dims of the model-stage dataset into samples and builds the design matrix from the selected variables and coordinate features (:mod:mapi_sklearn.design), dropping incomplete rows through the SDK row mask;
    2. fits one or more estimators for the plugin's uncertainty kind;
    3. persists them with skops or xgboost JSON (never pickle);
    4. at score time rebuilds the same columns, handles unseen levels (:mod:mapi_sklearn.levels), predicts and unstacks back to labelled arrays in the plugin's representation:

    ================= ===================== ========================================== base class representation predictions group ================= ===================== ========================================== SklearnModel point y_hat(*rows) (+ contributions) SklearnQuantile quantiles y_hat(quantile, *rows) SklearnBootstrap draws y_hat(chain, draw, *rows) SklearnConformal interval y_hat(bound=[lower, upper, point], *rows) SklearnClassifier point y_hat(*rows) = P(target == positive) SklearnMulticlass point y_hat(*rows, class) = P(target == class) ================= ===================== ==========================================

    Forecasting is direct only: future features must be supplied (or produced by the pipeline from coordinates); forecast_strategy: recursive raises RECURSIVE_UNSUPPORTED.

    SklearnModel ¶

    SklearnModel()

    Bases: CustomModel[SettingsT]

    Point-prediction plugin base class (representation point).

    Subclass it (or :class:SklearnQuantileModel, :class:SklearnBootstrapModel, :class:SklearnConformalModel, :class:SklearnClassifier), set id and version, and optionally override :meth:estimator.

    estimator ¶

    estimator(s: SettingsT) -> Any

    The estimator to fit: an allow-listed choice, {kind, params} or instance.

    The default returns settings.estimator.

    SklearnQuantileModel ¶

    SklearnQuantileModel()

    Bases: SklearnModel[SettingsT]

    Conditional quantiles (representation quantiles).

    xgboost fits one native multi-quantile model (reg:quantileerror); quantile-capable sklearn estimators (QuantileRegressor, GradientBoostingRegressor, HistGradientBoostingRegressor) fit one model per level.

    SklearnBootstrapModel ¶

    SklearnBootstrapModel()

    Bases: SklearnModel[SettingsT]

    Bootstrap ensemble (representation draws: chain=1, one draw per replicate).

    expected outputs are the replicate predictions (uncertainty of the fitted mean); predictive outputs add an out-of-bag residual drawn per cell, approximating the predictive distribution. Draws are joint across cells, so every aggregation is valid.

    SklearnConformalModel ¶

    SklearnConformalModel()

    Bases: SklearnModel[SettingsT]

    Split-conformal prediction intervals (representation interval, never draws).

    y_hat(bound=[lower, upper, point], ...) with attribute alpha: each interval covers the observed value with probability at least 1 - alpha for data exchangeable with the calibration rows. Intervals have per-cell coverage only and cannot be summed.

    SklearnClassifier ¶

    SklearnClassifier()

    Bases: SklearnModel[SettingsT]

    Binary classification: y_hat is the probability of positive_class.

    sklearn_schema_template ¶

    sklearn_schema_template(
    target_dtype: str = "float64",
) -> dict[str, Any]

    The model input schema template shared by the sklearn plugins.

    Every row dim is declared categorical with policy new_levels (strategy from settings.new_levels) except time_dim, which time_kind declares as an extending time/integer/index dim (time_kind: none: no such dim). The effective policy is the tighter of this and the data's own policy.

    Settings¶

    Settings of the scikit-learn / xgboost model plugins.

    A spec's model.settings for sklearn.* plugins looks like::

    estimator: {kind: xgboost.XGBRegressor, params: {n_estimators: 600, max_depth: 6}}
rows: [store, sku, time]               # dims stacked into samples
time_dim: time                         # the row dim that extends at forecast time
columns: {roles: [covariate]}          # which variables become feature columns
coord_features: {store: category, sku: category}
uncertainty: {kind: quantile, quantiles: [0.05, 0.5, 0.95]}
forecast_strategy: direct
retransform: median

    The uncertainty kind fixes the output representation, so each kind is its own plugin (sklearn.tabular_quantiles accepts only kind: quantile and so on).

    Estimator registry¶

    The allow-listed estimator registry.

    Plugins never import arbitrary classes. An estimator is chosen by kind from :data:ESTIMATORS, and its hyper-parameters are validated by that kind's Pydantic params model (extra="forbid", bounded values). The platform then builds the estimator with every parameter passed explicitly, so behaviour does not drift when a library changes a default. Parameters the platform owns (seeds, threads, categorical handling and the loss/objective an uncertainty kind needs) are not part of the params models.

    In a spec::

    estimator: {kind: xgboost.XGBRegressor, params: {n_estimators: 600, max_depth: 6}}

    LightGBM and CatBoost (v0.14) are an optional extra (mapi-sklearn[gbm]) and are imported only when an estimator of theirs is built or loaded; without them those kinds raise SETTINGS_INVALID.

    EstimatorEntry ¶

    EstimatorEntry(
    kind: str,
    module: str,
    name: str,
    params: type[Params],
    choice: type[_Choice],
    task: Task,
    persistence: Literal[
        "skops", "xgboost", "lightgbm", "catboost"
    ] = "skops",
    linear: bool = False,
    native_nan: bool = False,
    native_categorical: Literal["xgboost", "sklearn_hist"]
    | None = None,
    quantile: QuantileMode | None = None,
    quantile_setter: Callable[
        [dict[str, Any], float], dict[str, Any]
    ]
    | None = None,
    loss_param: str | None = None,
    quantile_loss: str | None = None,
    seed_param: str | None = "random_state",
    n_jobs_param: str | None = None,
    trusted: frozenset[str] = frozenset(),
    fixed: Mapping[str, Any] = dict(),
    description: str = "",
)

    Static facts about one allow-listed estimator.

    linear estimators expose coef_/intercept_ (exact additive contributions); native_nan ones accept missing feature values; native_categorical says how integer-coded categorical columns are declared (xgboost feature types or the categorical_features of sklearn's histogram boosting). quantile says how a quantile model is built: one native multi-quantile model, or one model per level with quantile_setter. loss_param/loss_default/quantile_loss name the loss or objective the quantile mode manages. trusted lists the extra types skops may load. fixed holds platform-owned constructor arguments (quiet logging, no files written).

    Built-in plugins¶

    The built-in sklearn.* model plugins (registered through the mapi.models entry point).

    Each plugin takes its estimator from settings.estimator; the uncertainty kind, and so the output representation, is fixed by the plugin:

    ========================== ============= ================================================== plugin representation uncertainty ========================== ============= ================================================== sklearn.tabular_regressor point none (contributions, retransform) sklearn.tabular_quantiles quantiles {kind: quantile, quantiles: [...]} sklearn.tabular_bootstrap draws {kind: bootstrap, n: 50, by: store} sklearn.tabular_conformal interval {kind: conformal, alpha: 0.1, calibration: 0.2} sklearn.tabular_classifier point binary class probability sklearn.multiclass_classifier point one probability per class (y_hat(..., class)) ========================== ============= ==================================================
